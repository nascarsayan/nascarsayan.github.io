## Things I built

### Personal developer CLI

Single Rust CLI (~50k lines, 230+ commits) replacing my shell and Python scripts: worktree per branch, ssh picker carrying my shell to any node, CI results fed back to agents, Claude Code ↔ chat bridge, agent guardrail hooks, redacted prompt archive. Code: [github.com/nascarsayan/valet](https://github.com/nascarsayan/valet).

<Badge tone="primary">Rust</Badge> <Badge tone="primary">systemd</Badge> <Badge tone="primary">chat bot API</Badge> <Badge tone="primary">Claude Code hooks</Badge>

<Fold summary="More detail">

- `repos`: bare clone plus a worktree per branch; PR numbers work as branch names; idle worktrees fold away.
- `ssh cluster`: fzf picker over every cluster, shared connections, my own zsh and tools on any node without touching root's dotfiles; only changed files upload.
- `cc`: mirrors Claude Code sessions to a chat DM so I can steer them from my phone; command grammar built for a phone keyboard (no dashes, no bangs).
- `ci watch`, `git review`: CI results and PR review threads synced into local files agents can read.
- `hooks`: ~15 guardrails for agents: steer to rg/fd, block /tmp writes, gitleaks before commits, never rewrite pushed branches.
- `apps`, `job`: ~60 pinned tools for amd64 and arm64; daily jobs for dotfiles, shared shell history with secrets templated out, cleanup. One systemd daemon supervises it all; `upgrade` lints, tests, rebuilds and swaps its own binary.
- Started as zsh functions and Python; rewrote in Rust for speed and zero interpreters.

</Fold>

### Docs site + diagram framework

Built in a week to explain clusters: typed specs, auto layout, animated walkthroughs. 150 diagrams: reviews, incidents, GPUs; teammates cloned it. Code: [github.com/nascarsayan/nascarsayan.github.io](https://github.com/nascarsayan/nascarsayan.github.io) (this site).

<Badge tone="primary">Astro</Badge> <Badge tone="primary">TypeScript</Badge> <Badge tone="primary">Custom layouts + lint</Badge> <Badge tone="primary">Bun</Badge>

<Fold summary="More detail">

- Diagrams are typed TypeScript specs. TALA gave the first layouts; our own column, sequence and nested layouts, components and validators took over, sized with real font metrics. The build fails on short or crossing arrows, overlapping labels, dangling references or diagrams that would need scrolling.
- Step-through walkthroughs with play/next, packets colored by response (2xx, 4xx, 5xx, hang), speed control and narration.
- 30+ components: explorers, decision trees, matrices, scrollytelling, terminal replays. Plus a comments server, search, glossary with shareable links, light/dark, and wiki export.
- Used for a before/after flow atlas of the control-plane service, Helm → Argo reviews, an incident write-up, GPU operator comparisons and simulated NVL72 racks.

</Fold>
